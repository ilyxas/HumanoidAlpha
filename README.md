# Humanoid Alpha

**Одна точка входа: `START.command`.**

Открой файл двойным щелчком или выполни:

```sh
./START.command
```

Выбери:

| Пункт | Режим | Что открывается |
|---|---|---|
| **1** | **Debug** | Полная консоль: суставы, моторы, диагностика, управление физикой. Position / Torque / Assisted. |
| **2** | **Experiment** | Экран тестировщика: Xandra, белый пол, камеры, часы и Screenshot. Моторы управляются через `humanoid`. Без страховочных сил. |
| **3** | **Harness** | Тот же чистый экран наблюдения и те же 33 мотора, плюс физическая страховка на тазе (внешняя сила, не фиксация позы). Стики мыши/геймпада: [HUMAN_CONTROL.md](docs/HUMAN_CONTROL.md). |
| **4** | **Animation** | Тот же экран, что в Experiment/Harness, но **без физики**: Xandra из `assets/Xandra_Animated.glb` проигрывается через AnimationMixer. Правый стик вверх (+X) — ходьба: чем выше, тем быстрее (×0.2…×2.0); отпустил — ходьба плавно останавливается. |
| **0** | **Stop** | Остановка проекта. |

Адрес для обоих режимов: **http://127.0.0.1:8788/**

Одновременно работает один режим. Для переключения останови текущий и выбери другой.
Терминал запуска должен оставаться открытым. **Ctrl+C** останавливает проект.
Первый запуск сам создаёт `.venv` и устанавливает зависимости; нужен Python 3.11–3.13.

## Прямой запуск

```sh
./START.command debug
./START.command experiment
./START.command harness
./START.command animation
./START.command stop
```

Отдельный `stop-project.command` также сохранён. Старые `start-console.command`
и `start-actuator-runtime` вызывают общий запуск с нужным режимом.

## Файлы

- `START.command` — запуск и выбор режима.
- `INSTALL_RU.md` — короткая инструкция для тестировщика.
- `humanoid` — существующий интерфейс актуаторов.
- `viewer/` — два экрана, включая белый пол и камеры в Observation.
- `physics/` — общая физика для обоих режимов.
- `assets/` — модель и физические оболочки столкновений.
- `tests/` — проверки; можно запускать во втором терминале во время работы.
- `docs/` — подробная техническая документация и прежние заметки.
- `reports/` — результаты проверок и журнал команд.

## Проверка

```sh
.venv/bin/python -m unittest discover -s tests -v
```

## Поставка

Актуальный архив собирается из этой папки:

```sh
.venv/bin/python scripts/package_release.py
```

Рядом с проектом создаётся `HumanoidAlpha_Delivery`: архив, инструкция и SHA-256.
`.venv`, временные файлы и журналы экспериментов в архив не включаются.
